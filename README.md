# One Line, One Laugh

A v1 entry for the make.fun bounty [One Line, One Laugh](https://make.fun/c/u-plucky-finch-20-one-line-one-laugh-0ffe66ea): a small Node program (`main.ts`) that deterministically writes one funny line of text, at most 200 characters, to `/output/entry.txt`.

The line: a neglected houseplant starts a podcast about its owner — the punchline lands inside the line itself, with no picture or setup needed.
